## Scripts

Ejecuta los archivos en PostgreSQL, en este orden y sobre una base de datos de prueba:

1. **`Scripts/scripts-crea.sql`**: crea las tablas del esquema.
2. **`Scripts/01_poblamiento.sql`**: agrega catálogos y datos de prueba.
3. **`Scripts/02_json.sql`**: actualiza y consulta atributos JSONB del perfil.
4. **`Scripts/03_consultas_03_07.sql`**: consultas de selección y JOIN.
5. **`Scripts/08_agregaciones.sql`**: consultas de agregación.
6. **`Scripts/09_10_11_12.sql`**: vistas, consultas preparadas y pruebas de rendimiento.

Los scripts incluyen operaciones de creación, inserción y modificación de datos. Revisa su contenido antes de ejecutarlos y no los corras sobre una base con información importante.

## Base de datos

Los adjuntos `red_pb.sql` y `red_pb.backup` no se incluyen en el repositorio porque contienen registros de usuarios con correos institucionales y valores en el campo de contraseña. Consulta `BaseDatos/README.md`.
